# 开始

下载 Releases 包后，解压到任意目录下，双击 MidiAutoBot.exe 运行即可。

# 使用

## 附加窗口

该工具在启动时会自动寻找已适配的 无限暖暖（Infinity Nikki） 客户端作为被附加的窗口。

此后，该自动化工具会自动将乐谱中的音符按键映射到已附加的窗口中。

如果希望自行选择附加的窗口，请执行以下步骤：
1. 点击 导航区 的 "设置"， 切换到设置页签
2. 点击 "被附加的窗口" 后的输入框
3. 从弹出的侧边栏中选择并点击希望被附加的窗口
4. 在弹出成功提示后，可关闭侧边栏

## 按键映射策略

该工具在解析midi乐谱文件时，会自动将乐谱中的音符根据按键映射规则映射到已附加的窗口中。

因此我们还需要设置一个键映射策略，该策略会决定乐谱中的音符所映射的按键。程序已内置了适配 无限暖暖（Infinity Nikki） 的 14键 和 21键 映射策略。

在程序运行时默认选择列表中的第一个映射策略

### 如何选择策略

1. 点击 导航区 的 "设置"， 切换到设置页签
2. 点击 "按键映射" 后的输入框
3. 从弹出的侧边栏中选择希望使用的按键映射策略并点击应用按钮
4. 在弹出的确认框中点击确认按钮
5. 弹出成功提示后，可关闭侧边栏

### 如何编辑按键映射策略

1. 点击 导航区 的 "设置"， 切换到设置页签
2. 点击 "按键映射" 后的输入框
3. 从弹出的侧边栏中选择希望编辑的按键映射策略并点击编辑按钮
4. 此时弹出的侧边栏中会出现一个音符与按键的映射表
5. 单击映射表中除表头以外的的单元格后，按下键盘上的按键即可将该音符映射到该按键
6. 双击映射表中除表头以外的的单元格可以删除该音符的映射
7. 点击 "保存" 按钮以保存修改
8. 随后回到映射策略列表中，点击 "应用" 按钮以重新应用按键映射策略

### 自动映射策略

由于大多数游戏中支持的键盘按键数量有限，因此该工具提供了一种自动映射策略，以扩展可以演奏的音符数量。
当 C#, D#, G#, A#, B# 的音符未配置按键时，该工具会自动将 C#, D#, G#, A#, B# 的音符映射到 C, D, G, A, B 的按键上。

**后续版本也将提供该策略的全局配置功能**

## 独奏

点击 导航区 的 "独奏"， 切换到独奏页签即可使用独奏功能

### 选择乐谱文件

1. 点击 "正在演奏" 后的输入框  
2. 从弹出的侧边栏中选择并点击乐谱文件
3. 在弹出成功提示后，可关闭侧边栏

### 选择音轨

1. 点击 "激活音轨" 后的输入框
2. 在弹出的下拉列表中点击选中希望激活的音轨

### 升降调

升降调功能实际为将键盘按键的映射向前后平移任意个八度

1. 点击 "升降调" 后输入框中的 上键 或 下键，逐级调整升降调，或者直接输入数字

### 键盘面板

在工具的独奏界面上，有一块虚拟键盘面板，该面板能够回显自动化映射到游戏中的按键。

同时当我们在该界面按下除功能键以外的部分按键时，也会自动映射到游戏中。

该虚拟键盘面板上的按键也支持通过鼠标点击触发。

### 播放面板

键盘上方有一块播放面板，该面板能够播放和调整当前乐谱的播放进度。
